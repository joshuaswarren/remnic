# The extraction judge shares model routing, fails open, and bounds deferral with a compact verdict protocol

Status: accepted

## Context
Judge-gated extraction depends on an LLM that may be slow, misrouted, or pathological, and its verdict/caching format has evolved across releases.

## Decision
The judge routes through the same shared resolution as every background task: taskModelChain wins over gatewayAgentId (gateway mode), so it never silently falls back to the persona/default chain. When modelSource is "gateway" the local LLM is skipped and the call goes straight to the gateway backend. The judge timeout comes from config, not a hardcoded value — a deployed local model needing tens of seconds previously aborted 100% of the time. Verdicts use a compact reply format ([{"index":N,"kind":"accept|reject|defer"}]) with a batch-scaled completion budget (24 tokens per candidate, capped at 2048); no reasoning is requested, keeping thinking models from spending the budget. A candidate deferred deferCap times is forcibly rejected; defer bookkeeping spans the whole call (identical candidates across batches share the first sighting's prior count), a single pass increments the cap once per content, and cap conversions count once per batch. Defer verdicts are never cached — caching would short-circuit the re-evaluation pass that is their purpose; accept/reject clear outstanding defer counters so reappearance starts fresh. Judge LLM failure fails open: the batch is approved, missing verdicts filled as approved, defer counts cleared so an outage does not cause early cap hits. `kind` is optional for back-compat: absent kind falls back to the legacy boolean, unknown kinds in cached entries drop to undefined, and missing durable resolves fail-open to durable=true. Telemetry observation payloads are built lazily only when a subscriber exists, and telemetry errors never block extraction. Training-time reads sort deterministically across platforms.

## Consequences
Fail-open means an outage approves candidates rather than deferring them; the defer cap trades a little recall for termination guarantees.
