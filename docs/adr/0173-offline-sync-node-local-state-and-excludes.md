# Node-local runtime state is excluded from offline sync on both sides

Status: accepted

## Context

Each node rebuilds its own live runtime state (SQLite WAL/SHM, derived indexes, spill queues, locks, decrypt staging, warm-cache markers); pushing it corrupts the remote's live state dir and trips retry loops, while a peer's copy of coherence state (e.g. a captured in-flight generation marker) breaks stamp probes forever. Older peers also list Finder junk, and exclusion checks sit on the enumeration hot path.

## Decision

Node-local runtime state is never synced in either direction: the default exclude list covers root and per-namespace `state/` dirs via leading `**/` globs, rotated impression archives and both durable pending spill directories (drained back into the synced active files before a snapshot, aborting the snapshot if durable rows cannot be folded so append-only history is never silently dropped), ledger locks, offline-decrypt staging dirs and their contents (a crash orphan must never be enumerable into plaintext push), embedding transaction leftovers, and the warm-cache generation marker on both push and apply sides. Node-local file absence in a push-filtered snapshot is NOT a delete instruction: stale base entries are dropped and local files left untouched, since deleting a live WAL/SHM would corrupt the local store. Case matters on APFS/NTFS: differently cased generation paths are refused like the canonical spelling. Operator-supplied excludes are compile-checked at parse time with per-entry errors, and `**` matches cross-segment wherever it appears; exclude checks are compiled once for the hot enumeration path. Drain scope follows snapshot scope: the global impression queue folds only when the snapshot root contains the active file (root snapshots, never namespace snapshots), per-namespace ledgers fold through their own storage so secure-store AAD stays namespace-scoped, an unresolvable namespace degrades to draining the rest, and token dirs decode back to namespace names (mapping the default token to the configured default) while names the router would reject are skipped rather than 500-ing the snapshot stream. Symlinked or escaping scan bases and children are rejected/skipped (non-fatal, never traversed through).

## Consequences

Live SQLite and append-only history survive sync; nodes never inherit each other's transient state; a hostile or stale incoming marker cannot overwrite the local one. Cost: the exclude list is the single source of truth and must grow with every new node-local artifact.
