# Relative event-time expressions resolve against the fact's source turn, with explicit years authoritative and backwards-looking bounds preferring the most recent past period

Status: accepted

## Context
Extraction attaches optional per-fact eventTime expressions ("yesterday", "since Q2", "until end of March", "2025-06") to facts. Facts are extracted in batches, replayed, and imported, so anchoring to Date.now() is wrong; periods wrap years (winter spans Dec-Feb), and naive end bounds cut seasons short or roll back too far.

## Decision
Every relative expression resolves against the fact's OWN anchor — the earliest span's observedAt turn where the claim was first uttered, never today's wall-clock — and batches pass per-fact provenance so identical phrases in different turns resolve differently. An explicit 4-digit year is authoritative and never derived from the anchor. Period resolution handles winter wraparound (Jan/Feb belong to the winter that started the previous December, for both start and exclusive end) and "since <bare period>" rolls back to the most recent PAST occurrence when the resolved start is future and no explicit year is given. Quarters: "last/next quarter" moves the quarter INDEX with year wraparound, while an explicit quarter number nudges the year only when the start month has passed or the quarter is ongoing. End bounds are exclusive starts of the following boundary: YYYY-MM spans its whole month; a named month or 3-month season advances by the full period; backwards-looking bounds build in the anchor year and roll back one year only when the boundary is genuinely future (never when the anchor is inside the named month or season). "until end of March" strips the prefix and resolves as "until March". Extraction wiring persists invalidAt at write time, applies the parent's expiry window to independently surfaced chunks so recall's validity check fires on chunks too, and the extraction schema keeps the event_time alias so gateway fallback parsing does not silently strip it (Zod strips unknown keys by default).

## Consequences
Replayed or imported sessions resolve historical expressions correctly but require accurate per-fact provenance; without it, batch-level anchoring applies. End bounds are exclusive-of-following-boundary, so "until 2025-06" includes all of June.
