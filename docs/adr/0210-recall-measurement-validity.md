# Recall measurements are computed against bounded, realistic, reproducible ground truth

Status: accepted

## Context
Recall metrics break silently in known ways: recall@5 against a 695-member topic is structurally capped near 0.007, making tier-policy deltas unreadable; min(k, relevant-set-size) as the denominator turns recall into precision; an ablation cell becomes a no-op when someone changes a config.ts default to match the cell's override while the baseline test still passes; fixture generators produce degenerate corpora (collapsed topic distributions, colliding topic words defeated by the tokenizer) from inputs that were never validated; and generated baselines drift when they embed wall-clock timestamps. The aged-dataset fixture is fully synthetic - no real user or client data.

## Decision
- Each query carries a bounded relevant set: the K most recently accessed members of its topic, capped at RELEVANT_PER_QUERY, selected with the same recency fallback chain (lastAccessed ?? updated ?? created) and the same id tie-break the ranker applies - so recall@K ranges over [0, 1] and the labeled set agrees with the ranker's top-K even on timestamp ties.
- recall@K divides by the total relevant items; min(k, |relevant|) is precision@K and is forbidden.
- The single-flag ablation matrix (issues #1574 and #1730) is canonical at 3 cells; every cell's flag flip must produce a different effective config than the baseline (from the config.ts default or a pinned override) or the ablation measures nothing; a drift test compares against the actually parsed config defaults. The contradiction axis is the inline write-path gate - the cron never fires during a bench replay.
- Committed baselines are the source of truth: generatedAt is pinned to a stable string (byte-stable across regenerations; wall-clock lives in git history); a fresh ablation run with the same seed must reproduce identical onScore/offScore/lift/CI values; acceptance requires lift >= 3 points.
- Fixture generators validate inputs at entry (integer topicCount; finite positive paretoAlpha and ageSkew) - silent degenerate corpora would report successful but useless results. Topic distribution uses the Pareto/Zipf inverse-CDF without clamping (a clamped second hotspot rivals topic 0); topics wrapping past the keyword table are disambiguated with a concatenated digit suffix (keywordN) that survives the ranker's [^a-z0-9] tokenizer; confidence tiers span all four production tiers; the query workload is Pareto-weighted and trimmed to MAX_TOTAL_QUERIES from the largest topics first, keeping a floor of one query per topic and dropping the smallest topics if still over the cap; the memory id-to-file lookup is hoisted out of the per-topic loop.
- The aged bench mirrors production: policy defaults match config.ts; every memory starts hot and is demoted once, as the tier-migration cycle would; the ranker matches whole-word tokens; plain aggregateTaskScores is used (this bench has no clean/dirty pairing semantics, so buildTieredAggregates would yield empty aggregates); the headline latency is the full-corpus figure with hotMs kept in details. Tests use loose bounds on tier outcomes so default changes in later PRs do not false-fail.
- Procedural recall: ablation rows whose expectNonNullSection only expresses gate-off behavior are skipped (no ON-side ground truth is derivable); non-integer or non-positive step order is rejected explicitly, never coerced (a rounded order changes both the written markdown and the recall scoring text); discrimination scenarios share verb and goal with the stored procedure but differ in the service noun or domain, so intent gating and the score threshold are what decide.
- The attribution CLI stages fixture facts so each pipeline stage's misses are distinguishable (written but not indexed, indexed but not recalled, cap-induced retrieval misses), and result-reference resolution validates files before resolving so a corrupt result surfaces as a stable not-found error - raw parse errors never reach CLI output.

## Consequences
Recall numbers are comparable across runs and tiers, but relevance beyond the bounded set is unmeasured. Baselines move only through deliberate regeneration. Fixture changes that shift the Pareto shape or tokenizer-visible text invalidate prior measurements. The ablation drift test depends on parsing real config defaults, so config loading must stay cheap and deterministic.
