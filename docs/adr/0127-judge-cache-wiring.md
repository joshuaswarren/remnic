# Judge wrapping is applied inside the benchmark run and always undone, never left on a reused adapter

Status: accepted

## Context
Benchmark runs optionally route judge calls through a content-keyed cache (issue #1573 PR1; PR #1591). Wrapping naively fails in several ways: mutating options.system.judge permanently replaces the adapter's judge, so a second run reusing the same adapter silently hits a stale wrapper or wraps the wrapper; a cache read that consumed the phase-timeout budget starves the judge on a miss; fire-and-forget cache writes lose entries to a follow-up run in the same process; two factory-created judges with identical source text but different closure-captured state collide on the same cache key; and class-based adapters with #private fields break when the judge is swapped through an Object.create shadow, because `this` no longer sees the private slots. Getter-only or frozen judge properties throw on assignment. AMA-Bench adds a separate cross judge whose calls must share the cache.

Theme consolidation: this record merges 3 sweep themes into one decision family (159 origin records): bench-judge-cache-wiring, benchmark-run-blocked-cause-walk, judge-override-proxy.

## Decision
- Compute cache wiring without mutating the caller's adapter. Apply judge wrapping inside the run's try block, after every setup step that can throw has succeeded, and restore the original judge in a dedicated finally that runs even when ingestion teardown throws.
- The cache wraps the phase-timeout-guarded judge: a cache hit returns before any phase budget is consumed, a miss hands the judge its full benchmarkPhaseTimeoutMs, and cache reads/writes run outside the phase timeout.
- Drain all pending cache writes before finalizing the report so a follow-up run with the same cache directory never misses still-pending entries.
- Wrap only judges identifiable by judgeProvider config. When noJudgeCache is set, no judge is wired, or no cache directory can be derived (neither judgeCacheDir nor outputDir), the system judge is left untouched, preserving the byte-identical baseline; providerless judges pass through unwrapped because otherwise two factory-created judges with identical source text but different closure-captured state collide on the cache key.
- The cache key carries the bench judge protocol version, the judge protocol variant, the role (primary vs cross), and the full judge configuration deterministically serialized with sorted keys; bump JUDGE_CACHE_PROTOCOL_VERSION when judge prompt/parse semantics change. The primary and cross judge share the same content-keyed cache; the cached cross judge is handed to the runner via a run-args override and options.amaBenchCrossJudge itself is never mutated.
- An explicit judgeCacheDir enables caching on its own (programmatic callers need no outputDir), and a leading `~` is expanded manually.
- Surface the judge-call counter on the run report whenever any judge was wrapped - including 0 on a fully cached re-run - and include cross-judge calls; never replace MemCorrect's explicitly counted specialized Responses calls with this wrapper's count.
- To install the wrapped judge, try in-place mutation first (preserves `this` for class-based adapters with #private fields); if the property is frozen or getter-only, fall back to a delegating proxy (createJudgeOverrideProxy) that overrides only `judge` and binds every other method to the original adapter. Never use Object.create shadowing.
- The custom benchmark path wires the cache the same way (wrap before scoring, restore + drain in a finally), and run-terminal errors are detected by structurally walking the error's cause chain so the contract survives wrapped or duplicated errors.

## Consequences
Reused adapters always get their original judge back, so no stale wrapper feeds verdicts into a later run, and cache hits cost no phase budget. Judges without identifiable provider config forgo caching, so their repeat calls are re-billed. Frozen/getter-only adapters take the proxy path. The always-written counter keeps the observability contract intact even when every verdict came from cache.
