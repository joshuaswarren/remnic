# Consolidation mutates durably and dependency propagation replays before ready

Status: accepted

## Context

Consolidation persists durable mutations (memory items, entity files, profile rewrites, lifecycle frontmatter, tier migrations, cleanup-only passes) directly to storage, bypassing the extraction write chokepoint, so the catalog `lastWriteAt` went stale. Dependency propagation replays primary mutations during recovery, where a crashed recovery run or a stale survivor lookup could deliver dependents against an uncommitted source. Profile rewrites raced concurrent appends.

## Decision

Every durable consolidation mutation, including cleanup-only passes with no LLM outputs, entity synthesis, profile rewrites, lifecycle writes, and tier migrations, is accumulated into a single flag and recorded as ONE consolidated catalog touch after all mutation-producing steps complete, just before returning. Deindex entries from INVALIDATE/MERGE collect into one batch flushed in `finally` (memories already invalidated on disk still de-index if a later iteration throws; loop errors still propagate after it). `updateMemory` preserves path/created/tags, so the survivor's temporal/tag index entry is already correct after a merge. A concurrent append during a profile LLM call skips the stale rewrite; the line cap trips next pass against the fresh profile. Contradiction auto-resolve is deferred until after `writeMemory` returns and clears pre-write `supersedes` links on blocked rows; propagation captures its inputs before the primary supersession so its own supersessions cannot recurse. Dependency propagation is bounded, one-hop, hook-placed after the successful primary operation, and hot-tier scoped (cold dependents are not scanned without cold write support). Recovery: merge preparation defers rather than persisting a job that cannot prove its replacement fingerprint; replay reconciliation reindexes/deindexes equivalently BEFORE a job becomes ready, and failed index work keeps it retryable; an expired `:recovery:`-owner lease MUST route back through primary replay before dependent delivery; lease claims fence against live owners and re-check expiry against the live clock. Orchestrator coordinators (conversation index, entity synthesis) are extracted modules whose dependencies are read through getters so post-construction reassignment is honored. The consolidation section parser uses a plain `$` end anchor after a polynomial ReDoS finding; captured lines are trimmed below, so behavior is unchanged.

## Consequences

Catalog freshness holds for every mutation path; dependents never consume an uncommitted source; recovery crashes converge. Cost: touch accounting requires every mutation site to set the flag, and recovery adds a replay phase before readiness.
