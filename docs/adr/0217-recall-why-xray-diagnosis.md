# Diagnosis surfaces (why/xray/explain) report outages as outages, validate inputs exactly, and render one shared, sanitized shape

Status: accepted

## Context
When a recall returns nothing, an operator cannot distinguish "the memory does not exist" from "the backend is down" or "a filter rejected it". Renderer surfaces print host-provided values into markdown tables, legacy snapshots lack fields newer renderers expect, and corrupted telemetry (NaN confidences, out-of-range dates, shifted edge arrays) arrives from disk or custom clocks.

Scope note: This file merges the recall-miss diagnosis (#3033), Recall X-ray (#570), tier-explain renderer, markdown escaping, and their test-strategy themes: one family of operator-facing diagnosis surfaces.

## Decision
Empty is never conflated with failed: a configured-but-unreachable search backend is an OUTAGE reported on the retrieval stage, and no downstream stage may claim it "considered 0"; no snapshot published is an honest zero-candidate state, distinct from outage; caller cancellation is the caller's decision, not an outage. Stage attribution follows the pipeline contract order — the planner gates retrieval, then policy filters run namespace → path → status — and both stage paths annotate the retrieval row from the SAME table, so a planner mode can never be reported on one path and dropped on the other; a mode with no note omits the key (byte-stable JSON). The LastRecallSnapshot is authoritative about what actually happened and is consulted before any predicate is re-evaluated. Inputs are validated exactly, never normalized first: a whitespace-only query is a caller fault; non-finite numbers are rejected explicitly rather than falling through comparisons; corrupt upstream values clamp to 0, never NaN; flags enable only via own-property checks so a doctored prototype cannot enable one. Namespaces on but no identity supplied refuses rather than diagnosing the global namespace (least-privileged default); an unreadable namespace contributes no candidates and the diagnosis still reports the readable ones. X-ray clones snapshots via structuredClone so callers cannot mutate them post-build, accepts null explicitly, and deep-copies scalar projections (trust, provenance) so getLastXraySnapshot is independent of the caller's object; clone must not silently drop fields (trust was once lost). Per-edge confidences align to graphPath: clamp into [0,1], require length == path-1 BEFORE per-element filtering, and reject the whole array on size mismatch or any non-finite member (filtering then length-checking silently shifts survivors onto the wrong edges). Renderers escape markdown cell content (backslash first, then pipes; newlines stripped) so a host value cannot break a GFM table; the tier-explain text block is ONE shared implementation asserted byte-for-byte across recall-explain and recall-xray so surfaces cannot drift; the shared "--- tier explain ---" block, JSON and text paths stay backwards-compatible; markdown adapters run legacy payloads through the same normalizer (malformed tierExplain drops to null) and propagate the recorded `source` into servedBy so markdown matches native x-ray output; LastRecallSnapshot does not preserve query text, so a placeholder is synthesized with queryHash/queryLen staying in JSON. Renderer robustness: out-of-Date-range timestamps coerce to "(unknown)" instead of RangeError-crashing; confidences are formatted to deterministic 4 decimals for stable golden files; misaligned snapshots are rejected wholesale rather than partially rendered; disclosure telemetry only attaches when present and well-formed via the shared isRecallDisclosure guard; tags normalize (trim, drop empties) identically to the recall-surface path. The degradation sink is the SAME array the pipeline fills (`options.degradationSink ?? []`), so an outage is observed, not inferred; sinks observe and never alter recall behaviour. Tests boot the real orchestrator (settling deferred init and destroying before temp-store teardown), stub only the read surface a recall touches with a reason-stated unchecked cast, and use deterministic fixture ids.

## Consequences
Diagnosis output is honest about gaps (unreadable namespaces, missing stages) but cannot invent per-stage detail the pipeline never captured. Renderer output changes require updating the shared implementation, not a surface copy. Corrupted snapshots degrade to placeholders instead of rendering partially.
