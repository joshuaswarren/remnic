# Every persisted provenance source must be grounded, timestamp-valid, validated on both write and read paths, byte-stable, and never crash extraction - an unverifiable span or fabricated date is a tagged state, not a silent failure.

Status: accepted

## Context
LLM-supplied quotes are untrusted text persisted into surfaces exposed to memory_get/x-ray/faithfulness, and Date.parse silently fabricates dates (fills missing components, rolls overflow, accepts bare numbers and impossible offsets); either failure mode would persist false evidence.

## Decision
Timestamp validity: turn timestamps are coerced to strict ISO-8601 before persisting a source (component round-trip catches wall-clock overflow; impossible timezone offsets the regex accepts are rejected via Date.parse; surrounding whitespace trimmed first); non-ISO shapes are accepted only through the year-led date guard - a COMPLETE, calendar-valid year-led prefix (numeric or textual month, real separator runs, day-not-the-hour lookahead) whose full (y, m, d) tuple Date.parse AGREES with, compared in the source's explicit offset frame or both local and UTC frames for offset-free input; M/D/Y and D/M/Y shapes are validated in both readings with overflow rejected; bare-year/numeric strings need a date/time separator; offsets are extracted only from range-validated, correctly anchored forms so date digits can never pose as an offset; a turn whose timestamp cannot be coerced is skipped for that source rather than pushed.

Quote grounding: the extraction-side post-parse validator locates each fact's quote in the buffered turns (after stripping a leading prompt role label - but preferring the RAW quote when it matches, so an utterance literally starting with [user]/[assistant] verifies as-is), builds ProvenanceSource entries with best-effort offsets, and never throws or drops a fact. A quote is verified even when normalized matching makes original offsets unrecoverable (record the source without charStart/charEnd). Quotes are capped at word boundaries, casefolded deterministically with toLowerCase, and sanitized before persisting - an unsafe quote cannot serve as evidence and its source is dropped entirely.

Attribution follows location: a located quote is attributed to the FIRST turn where it was found even when that turn's timestamp is un-coercible, never to the last turn; only an unlocated quote falls back to last-turn attribution. Under provenance.requireSpans, only a fact whose quote was located in NO turn is flagged for pending_review routing; a located-but-later-dropped source still satisfies the grounding requirement. The only exits that skip the flag are the disabled-feature exit and the unexpected-error catch - policy-neutral degradations.

Serialization is byte-stable (canonical key order, single JSON line matching the structuredAttributes precedent) and validated against the same Zod schema on write as on read, so invalid in-memory sources are dropped at write time, not silently lost on the next read. The verified/unverified tag requires surviving evidence - absent, empty, or all-invalid sources all downgrade to "none". Corrupt stored provenance is dropped, not poisoned forward. Config blocks are validated before defaults are applied, and present-but-invalid values are rejected rather than silently widened.

## Consequences
The single-normalizer rule (reuse collapseWhitespace) and schema parity add coupling; a normalized match preserves the source but loses exact offsets; requireSpans sends some otherwise-active facts to pending_review by design.
