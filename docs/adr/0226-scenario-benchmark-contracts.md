# Scenario benchmarks isolate every case, go through the adapter contract only, and score exactly what the scenario defines

Status: accepted

## Context
The remnic-native suites (bounded-memory-contracts, staged-memory, say-once, retrieval direct-answer/graph/reasoning-trace, state-views) share failure modes: cross-task recall bleed when sessions are reused, quick mode that hides one-sided regressions, metrics that count defer cases as wins, distractors that contaminate gold signals, fixtures that silently depend on wall-clock time, and benchmarks that bypass the adapter and end up measuring disk instead of retrieval.

## Decision
- Case isolation: every case gets a fresh session id so there is no cross-task recall bleed; scoped recall keeps a primary-namespace probe from pulling twin-namespace text.
- Adapter-contract fidelity: every case flows through the real adapter ingest/recall path - never raw files, because a benchmark that scores recall without going through recall is measuring disk and ships misleading perfect-recall numbers. The runner uses the registry's one-arg run contract with no mode parameter; a missing required memory adapter rejects rather than silently defaulting; budget/limit 0 means zero items (slice(-0) returns everything), and non-integer or non-finite limits are rejected.
- Quick mode must exercise both paths of a measured behavior - the positive recall path and the negative guard path (reasoning-trace), the full smoke subset with one task per family (bounded-memory) - so a one-sided regression cannot pass a smoke run.
- Bounded-memory contracts are pure and deterministic with one shared token budget across conditions; items are assigned to at most one slot (no double counting) with candidates ranked once by relevance then recency and offered to the first accepting slot; most-recent-first packing favors recent context (fair to the flattened condition); the raw boundary is lifted into a cited MemoryPackItem rendered with its mem:<id> citation and counted in retrieval/citation scoring (pre-claimed so it does not also occupy the boundaries slot); skills trigger via rule-based keyword matching (C3 only) and an injected skill's answer takes precedence on skill-positive tasks; skill outcomes reconcile against PACKED reality - a skill counts as injected only if it landed in the pack, and false negatives include skills the classifier never considered; recall is measured only over tasks whose point is recall (stale/wrong-scope traps have their own governance metrics); the MemoryContract type stays benchmark-local even though it could graduate into core later.
- Staged-memory runs on a verified corpus: the drift source is hash-checked at preflight (a tampered or unverified dataset fails loudly), error messages carry the basename only (the resolved directory can be an operator home path and this is a public repo), distractors come from fixed deterministic templates with synthetic entities only, distractor overlap is checked against subject/value/statement words of required AND forbidden facts (shared clause verbs are not overlap), gold rows cover the whole exposure window (current facts plus facts superseded inside it), a supersession pointer without a live successor is rejected rather than silently dropped, the oracle renders gold evidence with the same formatFactStatement the generator used, files follow strict versioned schemas with no wall-clock timestamps (pinned sentinel), statistics use seeded per-metric permutation (never Math.random), NA cost is reported in naMetrics and never silently blocks, the staged-input cost gate tolerates +10% over persist-only, recall is namespace-filtered, and orderings use a total order where equality returns 0.
- Direct-answer records winner_correct only on cases that expect an eligible verdict - hard-coding 1 for defer cases would inflate the aggregate mean and mask winner-selection regressions. The graph A/B's primary ship criterion is mean delta_p_at_3 >= 0 over a deterministic multi-hop PPR fixture. Reasoning-trace's baseline (boost disabled) runs the same helper path so latency is apples-to-apples, and its fixture scores mirror a realistic hybrid-rank distribution where the default boost must promote the traces. State-views treats the mode delta as the labeled history rows - never a change to which current rows surface.

## Consequences
Nothing can shortcut the adapter without failing the benchmark's own contract. Quick-mode slices must preserve balanced coverage. Strict schemas and determinism pins make every fixture change a versioned, deliberate act. Metrics that are not applicable to a scenario stay visible in the full bundle rather than disappearing from per-task scores.
