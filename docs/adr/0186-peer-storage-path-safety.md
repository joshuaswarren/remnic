# Peer files must never become a path-traversal or symlink-redirection vector.

Status: accepted

## Context
Peer storage lives inside an operator-writable memory directory, so peer ids and paths are attacker-adjacent: a crafted peer id or a planted symlink can redirect reads and writes outside the peers root.

## Decision
Every peer I/O entry point (read, write, delete, append, list, profile read/write) enforces the same layered path-safety contract:

1. Peer ids are validated by a linear-time regex (no overlapping match paths - the earlier ambiguous pattern backtracked exponentially) plus explicit adjacency checks for repeated separators; strict plain-object and string-type checks reject arrays, null, empty, and whitespace-only values instead of coercing them.
2. A lexical containment check ensures the resolved path stays inside the peers root; because this alone cannot see symlinks, every I/O site additionally calls the physical containment guard, which lstat-rejects symlinks and confirms realpath containment.
3. File opens use O_NOFOLLOW (kernel-level symlink refusal on the final component); because O_NOFOLLOW does not protect intermediate components, parent-directory inode stability is verified (open the parent with O_DIRECTORY|O_NOFOLLOW, hold the handle, compare fstat/lstat afterward).
4. The peers root itself is rejected if it is a symlink, and the root is validated by opening it before mkdir, then re-checking the created directory against the held inode, closing the check-to-mkdir TOCTOU window.
5. The safe-delete contract refuses to touch a peer file that is itself a symlink rather than guessing whether a removal would follow it; migration reads and writes go through the same guarded helpers, preserving the create-if-absent, non-overwrite migration contract.

## Consequences
Every file operation carries extra stat/open round-trips, and Node's handle-based readdir gap forces an inode-fence pattern rather than a kernel guarantee. Redundant defense-in-depth checks are intentional and must survive refactors: removing one layer reopens a documented TOCTOU or traversal window.
