# Namespace storage resolution, path containment, and identity normalization

Status: accepted

## Context

Namespace identifiers originate from operator config (`config.defaultNamespace`) and request-derived routing, so they are untrusted: a traversal segment could escape `<memoryDir>/namespaces` (CodeQL js/path-injection). Separately, whitespace-padded configured default names historically routed the default namespace to a tokenized non-default root, and repeatedly firing the resolve hook on every `storageFor` cache hit grew `namespaces.jsonl` without bound.

## Decision

Every on-disk namespace path is built through a containment check that rejects separators, parent references, and traversal segments (mirroring `isSafeRouteNamespace` without its 64-char cap, so identity tokens pass); safe segments resolve exactly to `path.join(base, segment)`. The default namespace is compared and rooted on the NORMALIZED (trimmed) identity everywhere, matching the catalog's normalized keys. The resolve hook fires only once per (namespace, storageDir) pair: marked permanently after success, retried on the next cache hit after a dropped registration, collapsed onto the single in-flight hook for concurrent bursts, and keyed by the pair so a changed dir still re-fires; it is serialized per key so a rejected hook never poisons subsequent notifications, and it fails defensively so a hook error never crashes storage resolution. Router-created storages mirror the primary orchestrator storage's wiring: hot-cache gate and TTL registered per root, inline-attribution template, post-write catalog touch, tombstone non-resurrection, secure-store context, and write-triggered prioritized embedding.

## Consequences

Traversal from namespace identifiers is structurally impossible; padded config values land in the same root as the live default dir; catalog append volume is bounded between rebuilds and dropped touches retry. Cost: containment rejects (rather than sanitizes) unsafe names, and hook dedup requires the (namespace, storageDir) key discipline.
