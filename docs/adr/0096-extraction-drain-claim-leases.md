# Extraction drains run through durable claims with lease and breaker discipline

Status: accepted

## Context

Out-of-process `remnic buffer drain` competes with live ingress for buffered turns; a killed drainer must not lose or double-extract turns; a failing extraction provider must not burn CPU or crash the daemon; and the backlog scheduler owns all persisted extraction backlog in one loop.

## Decision

Drains claim a session's turns into a durable claim file, and the claim IS the buffer for that run: every successful chunk is removed from it, so a kill leaves exactly the un-extracted turns, and the claim lock is released before entering the live buffer mutation queue to preserve the buffer-then-claim lock order. Claims run under leases with heartbeats: an unrenewable heartbeat aborts cleanly at the next chunk boundary (the next run resumes), a lost lease stops the run (never write into a claim you no longer own), and the lease is released only after the queued closure settles AND fully exits. A repeated failing chunk stays as durable retryable backlog: no drop, no side-file, never counted as processed. Empty-claim acks trust the ack verdict: live ingress may merge between read and ack, deferring instead of deleting the source. Only deliberately accepted captures drain (`captureMode=explicit`): ordinary buffered turns never create memories. The scheduler is one bounded daemon-owned loop: breaker-open bails before discovery I/O and a churn guard skips full claim reads while the window is open (foreground and claim drains accumulate toward one shared provider breaker); every detached rejection is caught (never an unhandled rejection terminating the server); the claim key is fenced synchronously before the async claim decision; page cursors rewind when submission stops mid-page or discovery fails after listing; ticks yield via setImmediate so pending I/O finishes; inFlight is the sole 'already submitted' authority; an empty claim is an authoritative tombstone; and chunk failure counts key on buffer key AND chunk fingerprint so a failure never follows a key to different content. Windows dedupe exact duplicates within one write scope, eligibility belongs to the RAW window (duplicate inflation never disqualifies), and oversized turns split into parts so no byte is lost to the render clamp. Drains use a dedicated local LLM client, and background drain work yields to fail-closed foreground flushes.

## Consequences

Kills, races, and provider stalls degrade to retryable backlog with zero turn loss and zero daemon crashes. Cost: claims/leases add durable bookkeeping, and breaker-open passes skip work that a half-open probe must later redo.
