# Deep recall runs one budgeted loop where every dependency races the shared deadline and only active, authorized memories enter the working set

Status: accepted

## Context
Deep recall iterates REFINE/EXPAND/STOP over a graph and calls several dependencies (seed search, graph load, hydration, policy LLM) that can hang, be slow, or belong to another principal. A seed search that never settles used to block the loop forever; a body-supplied namespace could read another tenant; private or governance-rejected memories leaked into the policy prompt; a zero-config value was silently reinterpreted.

## Decision
One totalTimeoutMs bounds the whole invocation; every dependency await races BOTH the shared deadline and the transport cancellation signal, and an abort propagates as a standard AbortError — never as ok:false and never as a partial result. Pre-policy work (seed search, graph load, hydration) is bounded by the same deadline; exhausting it yields the partial working set with a BUDGET_EXHAUSTED tail rather than a check that never runs. The policy call has two independent axes — its own stepTimeoutMs (0 disables only that axis) and the remaining shared budget; timeoutMs: 0 reaches the policy only when both are disabled. maxSteps: 0 is a documented disable value (seed-only retrieval) that dominates the loop condition; configured ceilings of 0 are honored no-ops. maxSteps from MCP/HTTP/CLI goes through ONE strict shared parser: absent means default, and "" or non-numeric strings are rejected rather than coerced or defaulted. Deep recall routes namespace, principal, and seed retrieval through the SAME shared read paths as other surfaces: the body namespace must pass the same effective-namespace allow-list (403 before the service), the caller's principal comes from the authenticated scope (never the client-supplied sessionKey), seed search uses the caller's namespace index (never the default collection), and collection-qualified seed forms the decoder cannot read are stripped, with foreign-collection hits skipped. Only ACTIVE memories enter the working set: graph and projection reads flow through the same active-source projection as harmonic recall, so rejected, quarantined, or private records behave exactly as on other read surfaces — absent, never an error, never content. Frontier scoring counts DISTINCT shared anchors only (one anchor counts once no matter how many working-set memories reach the candidate), and nodes whose sources are all inactive/unreadable cannot be re-offered. Seed backend failure is the only ok:false path; an empty index proceeds; re-search failure mid-loop is partial, not fatal; unavailable backends contribute [] and are reported ONLY through execution.onDegradation so a degraded run is never indistinguishable from a healthy empty index. Retrieval, rendering, and parsing are shared: seeds reuse the namespace search route, all deep-recall output uses the single shared markdown renderer (never fork formatting), HTTP/MCP glue lives in extracted seam modules, and entity-recall cancellation checkpoints sit at real I/O boundaries with yield/abort pairs so cancellation is the caller giving up, never a degradation. Related recall surfaces declare their policy through the unified recall spine: explicit-cue gathers cue evidence across the ordered read-key set into ONE shared accumulator (a fallback key's high-value turn references precede a primary key's lower-value lexical cues; deliberately NOT score-sorted because turn/content cues are unscored), entity mention caches key slots by scope with mention-epoch identity and at most one automatic follow-up rebuild per caller-started rebuild, alias scoring precomputes the query side once per query with an affix-contamination guard, non-English retrieval uses structural cues without a full coreference engine, direct answer is gated solely by the resolved capability with an empty-query short-circuit that never materializes candidates, action/observation traces are stored as paired turns including the preceding observation but never the following action, and parsers withhold stateful partial receipts until the full dependency chain is available. De-linearization runs temporal anchoring before coreference. Machine-derived session-experience writes use the salvage-mode envelope with warn-logged drops, and evidence classification is deterministic (a structurally identical clone does not change the class).

## Consequences
A degraded backend yields an explicit degradation report instead of a plausible-looking empty success. Strict parsing rejects malformed requests at the boundary instead of guessing. Cancellation checkpoints add yield overhead to long synchronous passes. The one-deadline model means pre-policy slowness consumes policy budget.
