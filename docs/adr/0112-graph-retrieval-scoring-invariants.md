# Graph edge extraction and scoring are order-independent, deterministic, and conservatively bounded

Status: accepted

## Context
Graph edges are extracted from batches of memories whose iteration order varies, and retrieval scores feed ranking; any order dependence, double-counted weight, or non-deterministic tie silently changes what the user recalls.

## Decision
Edge extraction is order-independent: all memories register as nodes first so cross-references resolve regardless of input order; a pre-scan of entity/agent claims lets the memory-target guard reject ids claimed as entities in the same batch whichever came first; a memory's own id is not entity-claimed by its own entityRef, and ids claimed by both roles stay memory nodes so cross-memory lineage references work. supersedes/lineage/derived_from edges must target memory nodes specifically — a non-memory-typed registration or a batch entity claim rejects the edge; dangling targets require includeDanglingEdges and register a memory node. entityRef edges either register a new entity node or target an existing entity node; an id already a memory node drops the edge rather than mutating a node's type. Ranking constraints: seedWeights keys must appear in seedIds (stale entries never override personalization) and seeds dedupe before share computation; node-weight priors apply only when the caller supplied no explicit weights, then renormalize; dangling PageRank mass redistributes proportionally to the seed vector; teleport retains (1-damping) per node; results sort by descending score with ascending-id tiebreak for determinism. Sub-floor-confidence edges drop at adjacency build, with a traversal-side defense in depth. Decay is monotone: reinforcement deltas below zero clamp to zero, perWindow rejects negatives, floor clamps to [0,1], the elapsed-window count uses ceil so boundary ages are not double-counted, decay can never raise a confidence already below the floor, and the anchor advances by exactly the charged windows (never to now, never unchanged) so cadence cannot under- or over-decay. The citation-extraction regex uses a greedy quantifier over a negated class excluding `[` to avoid polynomial backtracking. Causal phrase matching orders most-specific first. Snapshot queries filter half-open [since, +∞) with equality inclusive (a single-point pin must surface edges stamped at that instant), sort newest-first with from/to/type secondary keys, and load metadata lazily through a per-endpoint memoized cache bounded at 2×limit so a static cap never silently drops matching edges before the category filter sees them; an empty category allow-list is a 400, and metadata loader errors are best-effort (absent path, "unknown" category).

## Consequences
The memory-target guard can reject legitimate ambiguous references; conservative clamping means deliberately extreme operators (negative deltas, huge floors) are silently neutralized.
