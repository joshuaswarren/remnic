Stability: stable

Add `@remnic/plugin-devin`, a Devin CLI plugin that gives Devin sessions the same Remnic memory loop as the Claude Code and Codex plugins: SessionStart and UserPromptSubmit recall injected as additional context, PostToolUse observation with cursor/lock-safe flushes, PostCompaction and Stop/SessionEnd LCM coordination, the six Remnic skills, a memory-review agent, and a bundled stdio→HTTP MCP proxy that shares token resolution with the hooks. The shared hook runner gains ATIF transcript parsing (Devin CLI writes a single ATIF JSON document with `steps` rather than JSONL), a configurable transcript-path resolver, a cwd fallback through `DEVIN_PROJECT_DIR`/`CLAUDE_PROJECT_DIR`, and a `post-compaction` event alias; the Claude Code and Codex packages pick up the regenerated byte-identical runner copy.
